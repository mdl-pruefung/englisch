# Bewertung mündliche Prüfung Englisch (Beta)

Web-App zur Bewertung mündlicher Kommunikationsprüfungen (Sek I, EF, Q-Phase).
Alle Namen und Bewertungen bleiben auf dem jeweiligen Gerät – hier liegt nur das Programm.

- `docs/` – die veröffentlichte Web-App (GitHub Pages)
- `src/` – Quelltext; `python3 src/assemble.py docs --pwa` baut `docs/` neu
